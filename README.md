# 💌 Wedding Invitation

> A digital, interactive wedding invitation with a scroll-animated envelope reveal.

## 🚀 Quick Start
This project uses **CDN links**, so you don't need to install anything with `npm`.
1. Open the folder in your IDE.
2. View via localhost.

## 📂 Project Structure
* `index.html` - The main structure and GSAP library links.
* `js/main.js` - Controls the scroll animations.
* `js/translations.js` - Contains the text for English, Czech, and Turkish.
* `css/style.css` - Custom styles and the fixed language menu.

## 🛠 Features
* **Scroll-to-Open:** The envelope flap rotates and the letter slides out as you scroll.
* **Instant Translation:** Switch languages instantly using the top-right menu.
* **Mobile Friendly:** Designed to work on phones and desktops.
